• Task: #7 Title: Implement cross-scale attention mechanism
  URL: https://github.com/z3301/fathomnet/issues/7
  Author: z3301
  Labels: enhancement
  State: OPEN
  Milestone: Week 4
  Closed At: still open

  Description:
Add Transformer-style attention for ROI features to query environmental patches.

**Implementation details:**
- Implement CrossScaleAttention module with multi-head attention
- Based on Vaswani et al. 2017 'Attention Is All You Need'
- Q (query) = ROI features, K/V = context patch embeddings
- Requires switching to DinoV2 backbone for patch-level features

**Files to create:**
- `src/model_attention.py`

**Key components:**
- Multi-head attention (8 heads)
- Scaled dot-product attention: Attention(Q,K,V) = softmax(QK^T/sqrt(d_k)) * V
- Learnable Q/K/V projection matrices
- Residual connections and layer normalization

**Success criteria:**
- Attention module passes forward/backward
- Attention weights can be extracted for visualization
- Integration with multi-scale backbone from Week 3
