• Task: #16 Title: Dissect winning entry to gain better understanding of their methodology
  URL: https://github.com/z3301/CAP6415_F25_project-Kaggle-FathomNet/issues/16
  Author: z3301
  Labels: research
  State: CLOSED

  Description:
* Data preprocessing (A0.data_preprocess.py) queries the FathomNet/WoRMS taxonomy via fathomnet.api.worms, builds a biological tree, exports a class-to-class distance matrix, encodes rank-wise labels (Phylum→Species), and pickles label encoders used later for hierarchical supervision.
* Dataset pipeline (src/datautils.py) loads COCO-style annotations, crops ROI plus multi-scale context windows (3×, 5×, full frame), applies heavy augmentations (flip, jitter, rotations), optionally downsamples to simulate blur, and feeds each crop through HuggingFace AutoImageProcessor  configs tied to the ViT backbones defined in the config.
* Model core (src/model.py) instantiates separate Dinov2 encoders for ROI and each context scale, projects embeddings with ConcatEmb_ProjModel, and optionally routes ROI features through per-scale MultiLayerAttentionModels to attend over patch embeddings in the Multi-Context Environmental Attention Module; a LightningModule wraps training, adds a WarmupStepLR, and, when hierarchical_loss is true, loads the taxonomy labels and attaches a multi-head classifier for every biological rank (src/model.py).
* Training script (B1.BuildModel.py) consumes an OmegaConf config, remaps class ids to 0–78, optionally defines K-fold splits, builds Lightning dataloaders from Fathomnet_Dataset, wires WandB logging and checkpoints, and launches GPU training with mixed precision over the configured epochs.
* Inference/evaluation (C1.TestModel.py (lines 1-189)) disables augmentations, restores each fold checkpoint, recomputes embeddings per scale, runs the same intra-environment attention + classifier stack, and ensembles folds via majority vote before writing a Kaggle submission CSV under results/.
* Configurations such as config/experiment-final14.yaml  declare hardware setup, optimizer hyperparameters, ViT checkpoints (facebook/dinov2-large for both ROI and context), feature dimensionality, crop scales [3,5,-1], augmentation flags, and hierarchy metadata paths; swapping configs lets you recreate different experiments mentioned in the README note.
* Dependencies stay lean (requirements.txt): PyTorch Lightning, Transformers, WandB, scikit-learn, OpenCV, Pandas, etc.; install them after desired CUDA PyTorch wheel per README instructions.
